Phone setup

Android only lets a computer switch on background clipboard access. VoidBridge does it for you. This is a one-time step, and it survives reboots and app updates.

  1. Install VoidBridge on the phone and sign in or join

    Get the APK from the latest release. Join the same server account or sync code as this PC.

  2. Connect the phone to this PC

    On the phone: Settings → About phone, then tap Build number 7 times. Then in Developer options, turn on USB debugging and plug in a cable. Or, with no cable, use Wireless debugging below.

    Connect without a cable (Wireless debugging, Android 11+)
