# VoidBridge Server (Home Assistant add-on)

Runs the [VoidBridge](https://github.com/TheFormOfVoid/VoidBridge) server on
Home Assistant OS, e.g. on a Raspberry Pi. Your devices use it to sync one
end-to-end encrypted clipboard from anywhere.

Supports `aarch64` (Pi 3/4/5 with 64-bit HAOS), `armv7` and `amd64`.
Setup, including reaching it from the internet with DuckDNS, is in
[DOCS.md](DOCS.md).
